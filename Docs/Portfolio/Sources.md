公开审查也应覆盖 Git 历史中的原始素材。只删除最新版本的文件不会移除历史对象；如需移除受限资源，应一并处理相关历史或另建仅含可分发内容的展示仓库。

目录中的授权文本和来源记录继续随源工程保留；使用第三方素材时应以各自原许可为准。
